# М5 - Физический маятник

Моделируем маятник состоящий из стержня и шара. Рассчитываем момент инерции, исследуем зависимость периода от амплитуды, проверяем сохранение ЗСЭ и смотрим, как колебания затухают под действием трения. Результаты сравниваем с теоритическими рассчетами

## Отчёт

[Отчёт в PDF](docs/report.pdf)

## Вклад участников

- **Почевалов Арсений:** физическая модель, момент инерции, численное решение и проверка входных параметров.
- **Громыко Демид:** численные эксперименты, графики, тесты и составление отчёта

## Запуск

```bash
pip install -r requirements.txt
python src/main.py
pytest -q
```

Параметры задаются в начале `src/model.py`, Графики сохраняются в `docs/plots/`
